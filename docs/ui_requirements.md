# Требования к интерфейсу (GUI)

## 1. Основные сценарии

### Сценарий 1: Выдача книги
1. Библиотекарь входит в раздел "Выдача".
2. Вводит ID читателя (например, номер студенческого) и ISBN книги.
3. Система проверяет: а) наличие книги, б) не превышен ли лимит выдачи читателю.
4. При успехе: Система фиксирует выдачу (Дата выдачи, Планируемая дата возврата).
5. Результат: Сообщение "Книга выдана".

### Сценарий 2: Возврат книги
1. Библиотекарь входит в раздел "Возврат".
2. Вводит ISBN книги или ID операции.
3. Система определяет, была ли книга возвращена в срок.
4. При успехе: Система фиксирует возврат.
5. Результат: Сообщение "Книга возвращена" (возможно, с указанием штрафа).

### Сценарий 3: Поиск и просмотр статуса
1. Библиотекарь вводит часть названия книги или ФИО читателя в поисковую строку.
2. Система выводит список найденных элементов.
3. При выборе книги: отображается общее количество копий и доступное количество.
4. При выборе читателя: отображается список книг, которые находятся у него на руках.
