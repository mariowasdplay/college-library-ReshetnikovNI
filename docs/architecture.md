## 2. Описание слоев и потоков данных

1.  **GUI Client (`src/client_gui`)**: Уровень представления. Отправляет запросы в формате **JSON** на сервер и отображает результаты пользователю.

2.  **API Server (`src/server`)**: Уровень бизнес-логики. Принимает HTTP-запросы, выполняет проверки и через `storage.py` работает с файлами.

3.  **Потоки данных**: Обмен данными между Клиентом и Сервером всегда происходит в формате **JSON-сообщений** по протоколу HTTP.
    * **Пример**: Клиент отправляет запрос на выдачу книги (`POST /issue`) с телом `{"user_id": "U123", "isbn": "978..."}`. Сервер возвращает JSON-ответ `{"ok": true}`.

## 2. Форматы файлового хранилища

Данные проекта хранятся в двух форматах: CSV для статических списков (книги) и JSON для динамических записей (выдачи).

### 2.1. Книги (books.csv)

Хранится список всех книг в формате CSV.

| Поле | Тип данных | Описание | Инвариант |
| :--- | :--- | :--- | :--- |
| **isbn** | Строка | Уникальный номер книги | Уникален, не может быть пустым |
| **title** | Строка | Название книги | Не может быть пустым |
| **author** | Строка | Автор книги | Не может быть пустым |
| **total_copies** | Целое число | Общее количество экземпляров | >= 0 |
| **available_copies** | Целое число | Доступно для выдачи | available_copies <= total_copies |

### 2.2. Записи о выдачах (issues.json)

Хранится история всех операций выдачи/возврата в формате JSON (массив объектов).

| Поле | Тип данных | Описание | Инвариант |
| :--- | :--- | :--- | :--- |
| **user_id** | Строка | Идентификатор читателя | Не может быть пустым |
| **isbn** | Строка | ISBN выданной книги | Должен существовать в `books.csv` |
| **issued_on** | Строка | Дата выдачи | Формат YYYY-MM-DD |
| **returned_on** | Строка / null | Дата возврата | Формат YYYY-MM-DD или `null` |
