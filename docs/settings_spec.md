# Спецификация настроек типовой ИС

## 1. Файловые пути и Директории
Настройки определяют расположение данных.

| Параметр | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `DATA_DIR` | `./data` | Корневая папка для хранения данных |
| `BOOKS_FILE` | `books.csv` | Имя файла с каталогом книг |
| `ISSUES_FILE` | `issues.json` | Имя файла с историей выдачи |
| `LOG_FILE` | `app.log` | Файл для записи логов событий |

## 2. Бизнес-правила и Лимиты
Настройки, влияющие на логику работы библиотеки.

| Параметр | Значение (Default) | Диапазон | Описание |
| :--- | :--- | :--- | :--- |
| `MAX_ISSUES_PER_USER` | 5 книг | 1–10 | Максимальное кол-во книг на руках у одного читателя |
| `LOAN_PERIOD_DAYS` | 14 дней | 1–30 | Срок выдачи книги без штрафа |
| `DAILY_FINE` | 5.00 RUB | 0–100 | Сумма штрафа за каждый день просрочки |
| `POPULARITY_THRESHOLD` | 10 выдач | > 0 | Порог, после которого книга считается "Бестселлером" |

## 3. Системные настройки
| Параметр | Значение (Default) | Описание |
| :--- | :--- | :--- |
| `DEBUG_MODE` | `False` | Включает подробный вывод ошибок в консоль |
| `HOST` | `127.0.0.1` | IP-адрес сервера |
| `PORT` | `5001` | Порт API-сервера |
