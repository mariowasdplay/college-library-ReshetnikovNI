# Стандарт оформления кода (Coding Style)

В проекте используется стандарт PEP8 с следующими уточнениями:

## 1. Именование
* **Переменные и функции:** `snake_case` (например, `load_books`, `user_id`).
* **Классы:** `CamelCase` (например, `IssueRecord`, `Book`).
* **Константы:** `UPPER_CASE` (например, `ISO_FORMAT`, `API_URL`).

## 2. Структура модулей
1. Импорты стандартных библиотек (`os`, `json`).
2. Импорты сторонних библиотек (`flask`, `requests`).
3. Импорты локальных модулей (`common.models`).
4. Константы.
5. Классы и функции.

## 3. Типизация
Использовать Type Hints (подсказки типов) для аргументов и возвращаемых значений.
* `def find_book(isbn: str) -> Optional[Book]:`

## 4. Документация
Использовать Docstrings ("""...""") для описания назначения функций.

## 5. Длина строки
Стараться не превышать 100 символов.
