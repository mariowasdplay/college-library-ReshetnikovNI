# Отчет CP7: Клиент-сервер и транспорт/форматы сообщений

## 1. Описание API (Контракт)

Сервер работает на `http://127.0.0.1:5001`. Обмен данными происходит в формате **JSON**.

### 1.1. Поиск книг
* **Эндпоинт:** `GET /books`
* **Параметры:** `?q=<строка_поиска>`
* **Выход (Успех 200 OK):**
  ```json
  {
    "ok": true,
    "items": [
      {"isbn": "978-5...", "title": "...", "available_copies": 5}
    ]
  }
