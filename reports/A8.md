## 1. Руководство по установке

### 1.1. Системные требования
* **ОС:** Windows 10/11, Linux (Ubuntu 20.04+), macOS 12+
* **Python:** Версия 3.10 или новее
* **Свободное место:** 50 МБ
* **Сеть:** Локальный хост (127.0.0.1)

### 1.2. Пошаговая установка
1.  **Скачайте проект:** Клонируйте репозиторий или распакуйте архив в папку `college-library`.
2.  **Установите Python:** Убедитесь, что Python установлен, введя в терминале `python3 --version`.
3.  **Установите зависимости:**
    Выполните команду для установки Flask и Requests:
    ```bash
    pip install flask requests
    ```
4.  **Запустите Сервер (Backend):**
    Откройте первый терминал, перейдите в папку `src/server` и выполните:
    ```bash
    python3 api.py
    ```
    *Ожидаемый вывод:* `Running on http://127.0.0.1:5001`
5.  **Запустите Клиент (Frontend):**
    Откройте второй терминал, перейдите в папку `src/client_gui` и выполните:
    ```bash
    python3 app.py
    ```

### 1.3. Типичные ошибки и их решения
| Ошибка | Причина | Решение |
| :--- | :--- | :--- |
| `ModuleNotFoundError: No module named 'flask'` | Не установлены библиотеки | Выполните `pip install flask requests` |
| `ConnectionRefusedError` / "Сервер недоступен" | Клиент запущен, а сервер — нет | Сначала запустите `api.py` в отдельном окне, затем `app.py` |
| `Address already in use` | Порт 5001 занят | Убедитесь, что не запущена другая копия `api.py`. Закройте терминал и запустите снова. |

## 2. Руководство пользователя

### 2.1. Сценарий 1: Поиск книги
1.  Запустите клиентское приложение.
2.  На главном экране найдите поле ввода "Поиск".
3.  Введите название книги (например, "Морфий") или автора.
4.  Нажмите кнопку **"Найти"**.
5.  Убедитесь, что в таблице ниже отобразились только книги, соответствующие запросу.

### 2.2. Сценарий 2: Выдача книги
1.  Нажмите кнопку **"Выдать/Вернуть книгу"** в главном меню.
2.  В появившемся окне введите **ID Читателя** (например, `u001`).
3.  Введите **ISBN** книги (можно скопировать из таблицы поиска).
4.  Введите **Дату возврата** (в будущем).
5.  Нажмите кнопку **"Выдать"**.
6.  Убедитесь, что появилось сообщение "Успех", а количество доступных копий книги уменьшилось.

### 2.3. Сценарий 3: Возврат книги
1.  Нажмите кнопку **"Выдать/Вернуть книгу"**.
2.  Введите тот же **ID Читателя** и **ISBN**.
3.  Нажмите кнопку **"Вернуть"**.
4.  Если книга просрочена, система покажет уведомление о штрафе.
5.  Убедитесь, что книга принята (сообщение "Успех").

​4. Проверочные вопросы
​1. Какая одна неоднозначность в терминах пользователя может “сломать” поддержку?
Термин "Книга".
Пояснение: Пользователь может иметь в виду "Произведение" (Война и мир), а система оперирует "Экземплярами" (конкретная физическая книга с инвентарным номером). Если пользователь попросит "удалить книгу", администратор может удалить всё произведение из каталога вместо списания одного старого экземпляра.
​2. Какой фрагмент кода вы упростили так, что комментарий стал не нужен — и почему?
В функции calculate_fine мы использовали говорящие названия переменных: delta (разница дней) и daily_rate.
Пояснение: Раньше формула могла выглядеть как (d2 - d1) * 5, что требовало комментария. Теперь delta * daily_rate понятна любому, кто знает английский язык, и комментарий с формулой стал не нужен.
