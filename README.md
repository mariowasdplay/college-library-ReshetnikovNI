# college-library-ReshetnikovNI
Прототип информационной системы для автоматизации работы библиотеки колледжа. Реализован на архитектуре Клиент-Сервер.

Возможности
* **Учет книг:** Добавление, поиск, контроль экземпляров.
* **Обслуживание:** Выдача и возврат книг, расчет штрафов.
* **Рекомендации:** Умный подбор книг на основе истории чтения.
* **Отказоустойчивость:** Работа с файлами CSV/JSON, обработка ошибок.

Технологии
* **Backend:** Python 3.10+, Flask
* **Frontend:** Python Tkinter
* **Data:** CSV, JSON

Установка и Запуск

### 1. Требования
* Python 3.10 или выше.
* Библиотеки: `flask`, `requests`.

### 2. Запуск Сервера
```bash
cd src/server
python3 api.py
